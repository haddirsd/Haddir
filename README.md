# حاضر | Haddir

منصة سودانية لاكتشاف الفعاليات وحجز التذاكر إلكترونياً.

## خارطة التنفيذ
1. تأسيس المشروع والواجهة العربية RTL.
2. صفحات تفاصيل الفعاليات والحجز.
3. مراجعة التحويلات المالية يدوياً.
4. إصدار تذاكر QR بعد اعتماد الدفع.
5. لوحة الإدارة والاختبارات قبل الإطلاق.

الفعاليات المعروضة في النسخة الأولى ستكون بيانات تجريبية حتى ربط قاعدة البيانات.
